# Клипы упражнений

Упражнение в приложении показывает беззвучный клип на 3–6 секунд: он играет
сам, в цикле, без единого нажатия. Клипы лежат в `public/clips/<код>.mp4`,
постеры в `public/thumbs/<код>.jpg`, где код — короткий код поста Instagram
из ссылки вида `instagram.com/p/DTrPc9tExNW/`.

Нужны `yt-dlp`, `ffmpeg` и `node`.

## Порядок работы

### 1. Собрать ссылки

Профиль целиком `yt-dlp` без логина не отдаёт — на
`instagram.com/demicstory/` он падает с «Unable to extract data». Ссылки
берутся одним из трёх способов:

- из каталога: `node -e "const r=require('./src/data/reels.json'); console.log(Object.values(r.reels).map(x=>x.url).join('\n'))"`
- из открытого профиля через браузерные инструменты (страница пролистывается, ссылки `/p/…` и `/reel/…` собираются из DOM)
- от человека списком

Сложи их в файл, по ссылке на строку.

### 2. Собрать подписи

```
tools/fetch-captions.sh urls.txt > captions.tsv
```

Около двух секунд на ролик, так что полторы-две сотни ссылок — это минуты
пять; запускай в фоне. Скачивания видео здесь нет, тянутся только
метаданные.

### 3. Найти упражнение по подписи

```
node tools/captions.mjs captions.tsv                          # обзор
node tools/captions.mjs captions.tsv 'incline.*dumbbell'      # поиск
node tools/captions.mjs captions.tsv --full DTrPc9tExNW       # подпись целиком
```

Ищи по английским названиям: подписи английские, заметки в каталоге
русские. Полезные формы для одного упражнения обычно разные — `bulgarian`,
`split.squat`, `rear.?foot` — прогоняй несколько.

Подписи очень разной глубины. У части роликов там полный список
упражнений с подходами, и именно так находятся упражнения внутри
сборников: `DTrPc9tExNW` подписан как «Chest + Triceps Workout», а
наклонный жим гантелей идёт в нём четвёртым из шести. У других вся
подпись — одна строка, и состав по ней не узнать.

### 4. Проверить кадрами — обязательно

```
tools/reel-frames.sh DTrPc9tExNW            # весь ролик, 1 кадр в секунду
tools/reel-frames.sh DTrPc9tExNW 21 31 2    # отрезок, 2 кадра в секунду
```

Скрипт печатает путь к плитке из кадров — открой её и посмотри.

Подпись врёт про инвентарь: `DNdKE0dvqio` называется «The Correct Way to Do
Incline Bench Press», а на кадрах штанга, не гантели. И подпись ничего не
говорит про тайминг: в `DSf7V6ACkP2` румынская тяга занимает 17.3–20.8 с из
девяноста. Границы отрезка ищутся только глазами.

Хороший отрезок — одно-два целых повторения, 3–6 секунд, без склейки и без
заставки в конце.

### 5. Нарезать и подключить

```
tools/make-clip.sh DTrPc9tExNW 22.9 28.7
```

Потом:

1. Если ролика нет в `src/data/reels.json` — добавь запись: ключ это код
   поста, поля `category`, `note` (по-русски, своими словами), `author`,
   `url`. В `author` пиши реальный канал из второй колонки `captions.tsv`:
   demicstory репостит чужие ролики с упоминанием автора в тексте, так что
   по подписи легко записать не того.
2. Добавь `"video": "<код>"` в запись упражнения в `src/data/exercises.json`.
   Поле обязано указывать на существующий ключ в `reels.json` — это
   проверяет `src/data/data.test.js`, без записи в каталоге тест упадёт.
3. `npm test && npm run build`

В сборке смотри строку `precache N entries` — клип должен попасть в
офлайн-кеш. Если число записей не выросло, проверь `globPatterns` в
`vite.config.js`: расширение `mp4` там перечислено явно.

## Чего не делать

Не бери постер из `og:image` Instagram: в этот кадр впечатана кнопка
плеера, и ссылка через несколько часов протухает. Постер режется из самого
видео, `make-clip.sh` делает это сам.

Не встраивай ролик через iframe Instagram. Так уже было: событие `load`
у кросс-доменного фрейма не приходит совсем, а вместе с заглушкой это
давало два нажатия вместо одного и заметное ожидание. Ради этого клипы и
хранятся у себя.

Не подставляй похожее упражнение вместо точного. Если ролика нет —
`ExercisePreview` покажет силуэт с подсвеченной мышцей, и это честнее
чужого движения. На момент написания без ролика остался болгарский
сплит-присед: в 184 роликах каталога его нет, все совпадения на `lunge`
оказались выпадами с задней стопой на полу.
